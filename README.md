# نظام حساب الـ GPA وإدارة سجلات الطلاب الجامعية 🎓

تم تصميم وتطوير هذا النظام خصيصاً لحساب المعدل التراكمي (GPA) بدقة تامة طبقاً لجدول لائحة الساعات المعتمدة الرسمية المرفقة (**GPA Calculations - UNION - لجنة شئون الطلاب**).

---

## 🌟 المميزات الرئيسية للنظام

1. **حساب دقيق للمعدل التراكمي (GPA من 4.00):**
   - مطابقة تامة لجدول التقديرات والدرجات والساعات المعتمدة (من 1 إلى 6 ساعات).
   - حساب إجمالي الساعات المكتسبة والمسجلة، نقاط المواد (Grade Points)، ونقاط الجودة (Quality Points = Hours × Points).
   - حساب النسبة المئوية العامة وعرض التقدير العام (ممتاز، جيد جداً، جيد...).

2. **مرونة كاملة في إدخال درجات المواد:**
   - **بالدرجة الفعلية (Mark):** يتم حساب النسبة والتقدير تلقائياً حسب الدرجة العظمى للساعات المعتمدة (مثلاً: 3 ساعات = الدرجة من 150).
   - **بالنسبة المئوية (%):** إدخال النسبة المئوية مباشرة من 0% إلى 100%.
   - **بالتقدير المباشر (Letter Grade):** اختيار التقدير مباشرة (A+, A, A-, B+, B, B-, C+, C, C-, D+, D, F).

3. **إدارة بروفايلات الطلاب بكل خصوصية:**
   - إمكانية تسجيل أكثر من طالب؛ كل طالب بالاسم وبكلمة مرور من اختياره لحماية درجاته.
   - إمكانية التبديل بين حسابات الطلاب وتسجيل الخروج في أي وقت.

4. **إدارة المقررات الدراسية:**
   - إضافة، تعديل، وحذف المواد بسهولة.
   - تصنيف المواد حسب الفصول الدراسية (الفصل 1 إلى الفصل 8، أو فصل صيفي) مع إمكانية التصفية.
   - زر لطباعة السجل الأكاديمي أو تصديره إلى PDF.

5. **الربط مع Google Sheets:**
   - مزامنة سحابية لحفظ واسترجاع بيانات الطلاب والمواد في جدول Google Sheets تلقائياً أو بضغطة زر.
   - عمل التطبيق محلياً وبشكل فوري عبر المتصفح (LocalStorage) حتى بدون إنترنت أو بدون ربط Google Sheets.

6. **التذييل المطلوب:**

## 🚀 كيفية تشغيل البرنامج واستخدامه

1. افتح الملف [`index.html`](file:///c:/Users/mahmo/Desktop/test_2/index.html) في أي متصفح (مثل Chrome أو Edge أو Firefox).
2. أنشئ بروفايلك لأول مرة: أدخل اسمك وأي كلمة سر تختارها ثم اضغط **إنشاء بروفايل جديد**.
3. اضغط على **إضافة مادة جديدة** وأدخل اسم المادة وساعاتها ودرجتك.
4. ستجد الـ GPA والنسبة والساعات وإجمالي النقاط يتم حسابهم وعرضهم مباشرة!
